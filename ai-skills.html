How to use a downloaded skill

  1. 1
    Download the file

    Tap Download on any skill card above. You'll get a .skill file — no unzipping needed.

  2. 2
    Open Claude's Skills

    In Claude, go to Customize → Skills, tap +, then choose Upload a skill.

  3. 3
    Upload & switch it on

    Pick the .skill file you downloaded, then turn its toggle on — new skills start off.

  4. 4
    Start a new chat

    Just describe what you want — Claude uses the skill automatically when it fits.
